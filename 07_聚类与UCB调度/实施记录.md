# 阶段 07 实施记录：聚类与信息评分

状态：bin identity 聚类和双重 deterministic replay 已实跑；coverage-derived scoring / UCB 未开始。

## 算法来源与适配

- 来源仓库：`https://github.com/hellcat2q-stack/opentitan-aon-timer-paper-method-repro`。
- 来源 revision：`ab158f7a600aee4d5eccd009c7292224a26f346b`。
- 选定变体：`07_聚类与信息评分/algorithm_source/dbscan_clustering_new2.py`；源版本固定为 max cluster size 256、min_samples 2，分层 eps 为 `[0.3, 0.2, 0.15, 0.1]`，默认特征权重沿用原定义。
- `tools/stage07_clustering.py` 使用 Python 标准库实现对应特征提取、StandardScaler、Euclidean DBSCAN 和递归拆分。`PYTHONHASHSEED=0` 固定原算法中的字符串 hash 特征。
- 本实现只对 canonical identity 聚类；运行向量不参与聚类。无依赖安装，避免改变 Verilator/Cocotb 环境。

## 执行与证据

- 输入：`references/canonical_bin_ids.txt`；4,507 identities，其顺序和内容由阶段 03 catalog hash 校验。
- 命令：`PYTHONHASHSEED=0 python3 tools/stage07_clustering.py --bin-ids references/canonical_bin_ids.txt --output-dir evidence/stage07_initial --max-cluster-size 256 --seed 0`。
- 环境：WSL2 Ubuntu、Python 3.12.3；退出码 0。没有运行 RTL 仿真。
- 结果：4,507/4,507 identities 唯一映射到 78 个 clusters；cluster 大小 2–218，median 33，无 singleton，也没有超过上限 256 的 cluster。
- 程序内连续回放两次，完整 membership 一致；另在独立输出目录跨进程重跑，`sha256.txt` 内容完全一致。
- mapping SHA-256：`2856835a3118d2101c775b7c189734362b37627ceab17d38040a2f6e21a3bf33`。各产物 SHA-256 收录于 `evidence/stage07_initial/sha256.txt`，结构和限制见 `audit.json`。
- 输入 hash 为 canonical identity list 的 `dbcf02f06c121675401c8983dde65a9275239cefd3aff842712bdeef5da11355`。
