# 阶段 06 实施记录：覆盖矩阵与审计

状态：三态矩阵及稀疏 partial data 审计通过；exact canonical coverage data 阶段门未通过（2026-11-12）。

## 实现

- 新增 `tools/stage06_matrix.py`：读取 canonical identity catalog、阶段 05 corpus manifest 和可选逐 run vector，输出 CSV 矩阵及 JSON audit。
- 矩阵 schema：`aon-timer-stage06-matrix-v1`；每行代表一个 suite run；metadata 后固定列出 4,507 canonical identities。
- 数据契约：`1` = known hit，`0` = known miss，`?` = unknown。缺失 vector 产生 unknown；失败 run 保留行但其覆盖值全 mask 为 unknown；不能以失败执行奖励覆盖。
- vector 输入要求 schema `aon-timer-stage06-run-vector-v1`、匹配 run/revision/bin count/identity hash、只含 canonical ID、显式声明 `PARTIAL_VALIDATED` 或 `EXACT_VALIDATED`。complete vector 必须含全体身份且声明 exact。
- audit 输出 bin 数、identity hash、每 run 命中/未命中/未知数量、failed-run credit、union 及矩阵 hash。
